# 街コロオンライン（友人対戦用）

Render にそのままデプロイできる、Socket.IO ベースのリアルタイム対戦プロトタイプです。

## 機能

- 2〜4人のオンライン対戦
- ルーム作成・参加
- サイコロ1個/2個選択（駅完成後）
- 施設効果の自動処理
- 支払い処理を収入より先に実行
- 施設・ランドマーク建設
- ランドマーク4件完成で勝利
- ゲームログ表示

## 実装済みルール

- 初期状態: 麦畑、パン屋、3コイン、ランドマーク4件未完成
- ランドマーク: 駅、ショッピングモール、遊園地、電波塔
- 基本セット施設: 麦畑、牧場、パン屋、カフェ、コンビニ、森林、チーズ工場、家具工場、鉱山、ファミレス、リンゴ園、青果市場、スタジアム、テレビ局、ビジネスセンター
- 紫カードは各プレイヤー1種類につき1件まで

## 現時点の実装上の仮定

- テレビ局は「最もコインを持つ相手」から自動で5コイン取ります。
- ビジネスセンターはオンラインUIの選択処理が複雑なため、現バージョンでは効果なしとしてログ表示します。
- 電波塔の振り直しは、出目が気に入らない場合にボタンで1回だけ実行できます。
- 遊園地のぞろ目追加ターンは自動で同じプレイヤーの手番を継続します。

## ローカル起動

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開いてください。

## Render デプロイ

1. このフォルダを GitHub リポジトリに push
2. Render で New > Web Service
3. GitHub リポジトリを選択
4. Build Command: `npm install`
5. Start Command: `npm start`
6. デプロイ後のURLを友人に共有

`render.yaml` も同梱しているため、Blueprint としても利用できます。
